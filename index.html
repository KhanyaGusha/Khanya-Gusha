Task Insight Chat

Overview

Task Insight Chat is a live web application that pairs task management with a conversational interface, so understanding your workload is as easy as asking a question.

Problem

Task lists grow faster than they get read. Important items get buried, and getting a quick overview usually means scrolling and filtering rather than simply asking.

Solution

A chat-first experience: tasks live in one place, and a conversational assistant helps surface, summarise and make sense of them on demand.

My Role

I built and shipped the application, from the interface through to the chat-driven task insight experience.

Key Features

  • Conversational interface for exploring tasks
  • Instant insight into what needs attention
  • Clean, responsive layout
  • Live and publicly accessible

Challenges

Designing chat interactions that stay genuinely useful — answering the question asked, without burying the user in noise.

Impact

A shipped, live project that reflects where I am heading: practical, user-facing applications with AI at the centre of the experience.

MaintainX AI Operations Platform

Overview

MaintainX is an operations platform that uses AI assistance to help teams log, triage and resolve maintenance work faster.

Problem

Maintenance requests arrive unstructured — messages, calls, notes — making it hard to prioritise work and easy for issues to slip through.

Solution

A single platform where requests become structured work orders, with AI assistance helping to categorise, prioritise and route incoming work.

My Role

I am the project manager on MaintainX — planning and running the sprints, coordinating the team, tracking progress against the roadmap, and keeping the build aligned with what users actually need.

Technical Implementation

A React frontend backed by Supabase for authentication, database and storage, with AI features integrated for request triage. The work was organised and delivered across four sprints.

Key Features

  • Structured work orders from unstructured requests
  • AI-assisted categorisation and prioritisation
  • Status tracking across the resolution lifecycle
  • Supabase-backed auth, data and storage

Challenges

Designing AI assistance that is genuinely helpful — suggesting rather than overriding — while keeping the system dependable when the AI is uncertain.

Impact

The project is where my IT support instincts and AI engineering ambitions meet: better operations through practical, well-scoped AI.
